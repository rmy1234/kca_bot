# 시험 자료 출처 관리

실제 시험 자료의 원본, 출처, 이용 조건을 기록한다. 시드 커리큘럼과 RAG 자료는 이 문서에 등록된 자료만 근거로 삼는다.

## 1. 출제기준 (공식, 확보 완료)

| 파일 | 적용기간 | 쪽수 | SHA-256 |
|------|---------|-----|---------|
| `exam_criteria/정보보안기사_출제기준_2023-2026.pdf` | 2023.1.1 ~ 2026.12.31 | 14 (필기 8 + 실기 6) | `ac8c9015d51bc1975e66aa8ef63a024900ce07b6c1baabfce087c76bad726a07` |
| `exam_criteria/정보보안기사_출제기준_2027-2029.pdf` | 2027.1.1 ~ 2029.12.31 | 11 (필기 5 + 실기 6) | `23e78b2452db75e3a37c31b7e1aa263d890131c6e38d364a79eba1744ceb2352` |

  - 2023-2026: https://www.cq.or.kr/qh_cusgm10_002.do?bbscttNo=65 (첨부 1번)
  - 2027-2029: https://www.cq.or.kr/qh_cusgm10_002.do?bbscttNo=77 (첨부 1번, 2026-07-23 게시)
  - 첨부 다운로드: `https://www.cq.or.kr/ac_flecm02_001.do?atchFileId=<id>&fileSn=<n>` (fileSn 1=기사, 2=산업기사)
- 확보일: 2026-09-12
- 이용 조건: 2023-2026판은 공공데이터포털에 "이용허락범위 제한 없음"으로 등록됨(https://www.data.go.kr/data/15140079/fileData.do). 2027-2029판은 포털 미등록 상태이므로 KCA 저작권정책(https://www.cq.or.kr/copyrightPolicy.do)에 따라 출처를 표시해 사용한다.
- 저장소 공개 범위: 2023-2026판 PDF와 추출 텍스트만 git에 포함한다. 2027-2029판은 공공누리 표시가 확인되지 않았고, KCA 저작권정책상 공공누리 표시가 없는 자료는 담당자와 사전 협의 후 이용해야 하므로 `.gitignore`로 제외했다. 새 환경에서는 위 링크에서 직접 내려받아 같은 경로에 두고 SHA-256으로 원본을 확인한다.
- `.txt` 파일은 pdfplumber로 추출한 원문이다. 표 열이 한 줄로 합쳐져 있어 구조화 데이터로 바로 쓸 수 없고, 커리큘럼 반영 전에 수작업 정리가 필요하다.

### 시험 형식 (KCA 종목 안내 기준)

- 필기: 객관식 4지선다, 5과목 × 20문항, 150분. 매 과목 40점 이상, 전 과목 평균 60점 이상.
- 실기: 필답형, 180분, 100점 만점 60점 이상. 2023.1.1부터 단답형 12문항(36점) + 서술형 4문항(48점) + 실무형 2문항 중 1문항 선택(16점).

### 2027-2029판 주요 변경점

필기
- 시스템 보안: 클라우드 서버 유형(IaaS/PaaS/SaaS), 클라우드 운영체계와 인스턴스 메타데이터, 클라우드·컨테이너 구성 오류 위협, 분석 도구(Trivy, ScoutSuite) 추가. 분석 도구 예시에서 Kali Linux 제외.
- 네트워크 보안: 차세대 보안 솔루션(SASE, ZTNA, XDR) 추가, 네트워크 도구에 Wireshark, 공유에 SMB 추가. 네트워크 종류 예시 축소(Ethernet, SDN), RARP·VLAN 예시 제외.
- 어플리케이션 보안: FTP/메일/Web/DNS/DB 세세항목을 "개요 및 서비스 운영"과 "공격유형 및 대응 기술" 두 항목으로 통합.
- 정보보안 일반: 블록체인 개요, 주요항목 "최신 보안 동향"(양자내성암호, 딥페이크 AI, 표준화 동향) 신설.
- 관리 및 법규: 클라우드 보안 인증, 주요정보통신기반시설 보호제도, 사이버보안 법령(정보보호산업법, 클라우드컴퓨팅법, 전자서명법) 추가.

실기
- 가상화·클라우드 OS 특성, 클라우드 네트워크(VPC, Security Group), REST API 보안(OWASP API Security Top 10), EDR/EPP 차이 추가.
- 반복 취약점·미조치 항목 추이 분석, 개인정보 유출사고 원인 식별과 유출 위협요인 식별 추가.
- 주요항목 "보안관제 및 대응"을 "보안 로그 수집·분석 및 침해 대응"으로 개편, "최신 보안 동향"(양자내성암호, 동형암호, 경량암호) 신설.

## 2. 기출문제 (공식 공개본 없음)

- KCA는 필기 문제지를 응시자가 가져가게 하는 대신 별도 공개하지 않는다고 안내한다(https://www.cq.or.kr/qh_quagm12_001.do). 가답안은 시험 당일 18:00부터 게시 기간에만 열람할 수 있다.
- 제3자 수험 안내(https://www.inflearn.com/pages/information-security-engineer-exam-guide)에 따르면 2022년 1회 ~ 2023년 4회 필기는 PBT로 시행돼 문제지가 공개되었다. KCA 공지로는 확인하지 못했고, KCA 사이트에서 상시 제공하지도 않는다. 그 외 회차와 실기는 수험생 복원본뿐이며 정확성이 보장되지 않는다.
- 제3자 사이트(comcbt, kinz, cbtbank 등)의 기출은 KCA 원본이 아니며 이용 허락이 확인되지 않았다. 이 저장소에 원문을 수집·저장하지 않는다.
- `ReferenceQuestion` 등록 전 확인할 것: 원본 출처, 이용 허락(KCA 문의 1688-0013), 복원본 여부.

### 등록 정책 (2026-09-12 결정)

대상 시험은 2026년 시행분이므로 커리큘럼은 2023-2026판 출제기준을 따른다(`backend/app/curriculum.py`).

시스템에는 다음 세 가지만 등록한다.

| 자료 | 콘텐츠 관리 문서 유형 | 원문 등록 |
|------|-------------------|---------|
| 직접 보유한 문제지(응시 후 받은 문제지) | `기출문제` | 가능 |
| 개념 요약문 | `요약노트` | 직접 작성한 요약만 |
| 출제 경향 요약(회차·토픽별 출제 빈도, 자주 나오는 개념) | `출제경향` | 직접 작성한 요약만 |

- 인터넷에서 받은 기출·해설 파일은 참고해서 요약을 작성하는 데에만 쓰고, 파일이나 문제 원문은 업로드하지 않는다.
- `ReferenceQuestion.original_text`에는 직접 보유한 문제지의 문항만 넣고, `note`에 회차와 출처를 적는다.
